# Architecture

## Current executable surface

The checkout contains repository validation tools, their dedicated tests, workflow definitions and documentation. No domain package, benchmark runner, codec implementation or qualified result is available. Repository metadata keeps capabilities and claims empty.

## Intended data flow

A prespecified dataset, source codec, configuration, trial and execution lane determine each planned cell. An admitted SLOG/NPY reader retains the exact source events and an injective binary-raster mapping. A source-bound adapter invokes the actual imported codec. The runner retains payload bytes, complete decoded output, independent metric inputs, separate encode/decode samples and direction-specific memory observations. Reports preserve every terminal failure and inconclusive result.

## Ownership

The benchmark owns adapters and measurement, not codec equations. SC-NeuroCore owns algorithms, decoder and predictor backends. Evidence Manifest Toolkit owns canonical evidence assembly, sealing and verification. Spike Format Bridge owns optional vendor conversion. Studio and Neuro Evidence Bench are downstream consumers, not alternate metric engines.

## Validity and recovery

The planned result remains one cell. Complete matrix acceptance requires exact equality of expected and terminal cell identities. A missing waveform decoder stays visible. A lossless verdict requires actual complete decoded source equality plus the declared zero-distortion criteria. Fresh physical measurements have fresh identities; reanalysis cannot replace them. Resume verifies unchanged source/protocol and complete artifacts, preserving prior failures and interrupted attempts.

Further public tooling details are in [the documentation architecture](docs/ARCHITECTURE.md).
